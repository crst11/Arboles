# Ejemplos de Árboles en C#

Este proyecto contiene ejemplos de implementación de estructuras de datos tipo árbol utilizando C#.

## Descripción

Se desarrollan distintos ejercicios donde se representa información de forma jerárquica mediante árboles, aplicados a casos como:

- Organización familiar
- Administración de una tienda
- Sistemas de usuarios y componentes de software

## Conceptos aplicados

- Estructuras de datos tipo árbol
- Programación orientada a objetos
- Herencia
- Polimorfismo
- Recursividad
- Organización de proyectos en carpetas (Models y Services)

## Objetivo

Practicar la implementación de estructuras de datos en C# aplicadas a problemas de la vida real y escenarios de desarrollo de software.

## Tecnologías utilizadas

- C#
- .NET Console Application

## Estructura del proyecto

- Models/
- Services/
- Program.cs
